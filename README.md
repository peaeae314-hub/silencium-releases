# Silencium · 更新托管

公开托管 `version.json` 与 release APK，供 App 应用内更新检查。
对齐宝可梦手帐（`pokemon-handbook-releases`）同一 GitHub 账号与同一套清单字段。

- 清单（jsDelivr）：`https://cdn.jsdelivr.net/gh/peaeae314-hub/silencium-releases@main/version.json`
- 清单（GitHub Releases latest，推荐）：发版后把 `version.json` 挂到 Release 附件，用
  `https://github.com/peaeae314-hub/silencium-releases/releases/latest/download/version.json`
- APK：见 [Releases](https://github.com/peaeae314-hub/silencium-releases/releases)

源码仓库：https://github.com/peaeae314-hub/Silencium
